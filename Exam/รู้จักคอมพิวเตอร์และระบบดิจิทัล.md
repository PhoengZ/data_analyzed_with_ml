- ตัวเลือก 2 อธิบายภาษาโปรแกรมระดับสูง (high-level programming language) เช่น C, Java, Python ซึ่งเป็นภาษาที่มีโครงสร้างและ abstractions สูงกว่าภาษาแอสเซมบลีมาก

- ตัวเลือก 4 อธิบายเกี่ยวกับการกำหนดรูปแบบการทำงานร่วมกันของอุปกรณ์ในระบบคอมพิวเตอร์ ซึ่งไม่เกี่ยวข้องโดยตรงกับภาษาแอสเซมบลี

อธิบาย:

ระบบปฏิบัติการ (Operating System) มีหน้าที่หลักในการจัดการและควบคุมการทำงานของฮาร์ดแวร์และซอฟต์แวร์ในระบบคอมพิวเตอร์ หน้าที่หลักๆ ของระบบปฏิบัติการประกอบด้วย:

1. **จัดสรรทรัพยากรในระบบคอมพิวเตอร์ให้ซอฟต์แวร์ต่างๆ**: ระบบปฏิบัติการมีหน้าที่จัดการและจัดสรรทรัพยากรต่างๆ เช่น CPU, หน่วยความจำ (RAM), ฮาร์ดดิสก์, และอุปกรณ์อื่นๆ ให้กับซอฟต์แวร์ต่างๆ ที่กำลังทำงานอยู่ในระบบ เพื่อให้ซอฟต์แวร์สามารถทำงานได้อย่างมีประสิทธิภาพ

2. **ควบคุมสิทธิการใช้งานของผู้ใช้ในการเข้าถึงทรัพยากรต่างๆ**: ระบบปฏิบัติการมีหน้าที่ควบคุมและจัดการสิทธิการใช้งานของผู้ใช้ในการเข้าถึงทรัพยากรต่างๆ ในระบบ เช่น การกำหนดรหัสผ่าน, การจำกัดการเข้าถึงไฟล์หรือโฟลเดอร์, และการควบคุมการใช้งานอุปกรณ์ต่างๆ เพื่อความปลอดภัยของระบบ

3. **ติดต่อกับข่ายงานคอมพิวเตอร์**: ระบบปฏิบัติการมีหน้าที่ในการจัดการและควบคุมการเชื่อมต่อกับเครือข่ายคอมพิวเตอร์ เช่น การเชื่อมต่ออินเทอร์เน็ต, การแชร์ไฟล์และเครื่องพิมพ์ในเครือข่าย, และการสื่อสารกับอุปกรณ์อื่นๆ ในเครือข่าย

ดังนั้น ทุกตัวเลือกที่ให้มา (1, 2, และ 3) ล้วนเป็นหน้าที่ของระบบปฏิบัติการ ทำให้ตัวเลือก 4 ("ถูกทุกตัวเลือก") เป็นคำตอบที่ถูกต้อง.

การเก็บข้อมูลภาพ (Image Data) มีหลายวิธีและหลายรูปแบบ แต่ละวิธีมีลักษณะเฉพาะและใช้สำหรับจุดประสงค์ที่แตกต่างกัน ดังนี้คือรายละเอียดเกี่ยวกับแต่ละตัวเลือก:

1. **การเก็บข้อมูลสีของภาพสีเป็นการเก็บข้อมูลองค์ประกอบของสีที่ทำให้เกิดสีนั้นๆ ขึ้น** - ถูกต้อง การเก็บข้อมูลสีของภาพสีโดยทั่วไปจะเป็นการเก็บข้อมูลเกี่ยวกับองค์ประกอบของสี (color components) ที่ทำให้เกิดสีนั้นๆ ขึ้น ระบบสีที่พบมากที่สุดคือ RGB (Red, Green, Blue) และ CMYK (Cyan, Magenta, Yellow, Key/Black) สำหรับภาพสี RGB จะเก็บข้อมูลของสีแดง เขียว และน้ำเงิน ที่ผสมกันในแต่ละพิกเซล (pixel) เพื่อสร้างสีต่างๆ

2. **การเก็บข้อมูลภาพทำได้โดยแบ่งภาพเป็นจุดเล็กๆ และเก็บสีของแต่ละจุดนั้น** - ถูกต้อง ภาพดิจิทัลถูกแบ่งออกเป็นตารางของจุดเล็กๆ ที่เรียกว่า "พิกเซล" (pixel) แต่ละพิกเซลจะมีค่า RGB กำหนดสีของมัน การแสดงภาพบนจอแสดงผลหรือการพิมพ์ภาพ จะเป็นการรวมพิกเซลเหล่านี้เข้าด้วยกันเพื่อให้เกิดเป็นภาพที่เรามองเห็น

3. **การเก็บข้อความภาพสามารถทำได้โดยเก็บข้อมูลสมการที่ใช้ในการวาดเส้นให้เกิดภาพนั้น** - ถูกต้อง สำหรับภาพที่เกิดจากสมการทางคณิตศาสตร์ เช่น กราฟิกแบบเวกเตอร์ (Vector Graphics) จะเก็บข้อมูลภาพในรูปแบบของสมการที่ใช้ในการวาดเส้นโค้งและรูปร่างต่างๆ ที่ประกอบกันเป็นภาพ ภาพประเภทนี้สามารถปรับขนาดได้โดยไม่มีการสูญเสียคุณภาพ ตัวอย่างของรูปแบบไฟล์ภาพที่ใช้การเก็บข้อมูลในลักษณะนี้ ได้แก่ SVG (Scalable Vector Graphics)

ดังนั้น ทุกตัวเลือกที่ให้มา ล้วนเป็นวิธีการเก็บข้อมูลภาพที่ถูกต้อง แต่ละวิธีมีลักษณะเฉพาะและเหมาะสมกับการใช้งานที่แตกต่างกันไป เช่น ภาพถ่ายโดยทั่วไปจะใช้การเก็บข้อมูลแบบพิกเซล (bitmap) ในขณะที่กราฟิกและภาพวาดที่ใช้ในการออกแบบ อาจจะใช้รูปแบบเวกเตอร์มากกว่า
